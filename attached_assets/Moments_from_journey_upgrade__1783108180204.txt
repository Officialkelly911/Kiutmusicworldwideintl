KIUT MUSIC WEBSITE

MOMENTS FROM THE JOURNEY

Complete Premium Upgrade Roadmap

Vision

Transform the “Moments From The Journey” section from a standard image gallery into a cinematic storytelling experience that captures Kiut’s artistic journey.

The gallery should feel less like a collection of photos and more like an immersive visual documentary.

Target style:

	•	Premium
	•	Editorial
	•	Cinematic
	•	Emotional
	•	Luxurious
	•	Modern
	•	Interactive
	•	Story-driven

⸻

1. Reduce the Number of Images

Current Issue

The gallery contains too many images, causing visual fatigue.

Improvements

	•	Display only the strongest 12–18 images initially.
	•	Hide additional photos behind a “View Complete Journey” or “Explore Full Gallery” button.
	•	Remove duplicate or near-identical images from the same event.

⸻

2. Improve Image Selection

Every image should tell a different story.

Choose photos that represent:

	•	Live performances
	•	Recording sessions
	•	Fan interactions
	•	Backstage moments
	•	Media appearances
	•	Lifestyle
	•	Travel
	•	Milestones

Avoid multiple photos with identical compositions.

⸻

3. Editorial Layout

Replace the repetitive grid with an editorial composition.

Use:

	•	Large feature images
	•	Portrait cards
	•	Landscape cards
	•	Square images
	•	Full-width hero images

Create intentional visual rhythm.

⸻

4. Featured Moment

Introduce a full-width featured image at the top.

Include:

	•	Event title
	•	Location
	•	Year
	•	Short caption
	•	“Explore Story” CTA

This image should act as the visual anchor.

6. Better Cropping

Correct all improperly cropped images.

Requirements:

	•	Preserve faces
	•	Avoid cutting off heads
	•	Maintain aspect ratio
	•	Use object-fit: cover
	•	Use object-position: center
	•	Display every uploaded image correctly

Remove broken image placeholders.

⸻

7. Premium Card Styling

Cards should feature:

	•	Rounded corners
	•	Soft shadows
	•	Elegant spacing
	•	Overflow hidden
	•	Thin subtle borders

No harsh edges.

⸻

8. Hover Effects

Desktop hover:

	•	Image zoom (1.03–1.05)
	•	Soft gold glow
	•	Increased shadow
	•	Gentle lift animation

Keep interactions smooth and subtle.

⸻

9. Image Labels

Display optional labels such as:

	•	Studio Session
	•	Live Performance
	•	Behind The Scenes
	•	Interview
	•	Festival
	•	Fans
	•	Tour

Only use labels where meaningful.

⸻

10. Scroll Animations

Implement staggered scroll reveals.

Use:

	•	Fade in
	•	Slight upward movement
	•	Stagger timing

Duration:

0.6–0.8 seconds.

⸻

11. Fullscreen Lightbox

Clicking an image should open:

	•	Fullscreen viewer
	•	Dark cinematic background
	•	Previous / Next controls
	•	Keyboard navigation
	•	Swipe support
	•	Captions
	•	Event information

⸻

12. Journey Statistics

Place a milestone section above the gallery.

Examples:

	•	Countries Performed
	•	Concerts
	•	Fans Reached
	•	Years Performing

Style with elegant counters.

⸻

13. Premium Spacing

Increase whitespace throughout the section.

Improve:

	•	Vertical spacing
	•	Card spacing
	•	Heading spacing

Allow the gallery to breathe.

⸻

14. Merchandise-Quality Presentation

Images should feel collectible.

Use:

	•	High resolution
	•	Lazy loading
	•	Optimized rendering
	•	Smooth loading transitions

⸻

15. Gallery Ending

Replace the abrupt ending with a cinematic CTA.

Example:

“The Journey Continues…”

Buttons:

	•	Watch Latest Visual
	•	Listen Now

⸻

16. Performance

Optimize:

	•	Lazy loading
	•	Responsive image sizes
	•	Smooth animations
	•	Layout stability
	•	Fast loading

⸻

Final Goal

The Moments From The Journey section should become one of the most memorable parts of the Kiut Music website, delivering an immersive visual story that feels like browsing a premium artist documentary rather than a standard photo gallery.
