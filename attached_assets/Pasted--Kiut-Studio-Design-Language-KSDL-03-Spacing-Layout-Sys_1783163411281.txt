# Kiut Studio Design Language (KSDL)

# 03 – Spacing & Layout System

Version: 1.0

Status: Active

Last Updated: July 2026

---

# Purpose

The Spacing & Layout System establishes a consistent spatial rhythm across the Kiut Music website.

It defines how content is positioned, how sections relate to one another, and how whitespace contributes to the premium, cinematic experience.

Every page should feel balanced, breathable, and intentional.

---

# Design Philosophy

Whitespace is an active design element.

Space improves readability.

Space creates luxury.

Space directs attention.

Every margin and every padding value should have a purpose.

---

# Base Grid System

The Kiut website uses an **8-point spacing system**.

Every spacing value should be a multiple of 8 whenever possible.

Examples:

---

# Alignment Rules

Headings align with content.

Buttons align with cards.

Images align with grids.

Icons align with text baselines.

Sections align with container edges.

---

# Responsive Layout

Mobile First

Every layout begins with mobile.

Tablet expands the experience.

Desktop enhances rather than redesigns.

---

# Layout Do's

✔ Use consistent spacing.

✔ Maintain alignment.

✔ Allow breathing room.

✔ Prioritize readability.

✔ Keep layouts modular.

---

# Layout Don'ts

✘ Don't crowd content.

✘ Don't mix spacing values randomly.

✘ Don't stretch content beyond readable widths.

✘ Don't use inconsistent border radii.

✘ Don't create one-off layouts.

# Implementation Checklist

Before merging any new layout:

□ Uses approved spacing tokens

□ Uses approved container widths

□ Maintains grid consistency

□ Aligns with neighboring sections

□ Preserves responsive behavior

□ Matches border radius standards

□ Keeps vertical rhythm intact
