# Kiut Studio Design Language (KSDL)

# 10 – Responsive System

Version: 1.0

Status: Active

Last Updated: July 2026

---

# Purpose

The Responsive System defines how the Kiut Music website adapts across all supported screen sizes.

Responsive design is more than scaling layouts. It ensures every visitor enjoys the same premium experience regardless of device.

The website follows a Mobile-First philosophy.

---

# Design Philosophy

Every screen deserves a premium experience.

Layouts should adapt naturally.

Interactions should remain intuitive.

Performance should improve on smaller devices.

Navigation should become simpler, never weaker.

# Images

Use responsive image sizes.

Prefer WebP.

Lazy-load below the fold.

Avoid layout shifts.

Never upscale low-resolution assets.

---

# Video

Autoplay only when appropriate.

Mute by default.

Provide poster image.

Reduce resolution on slower devices.

---

# Performance

Reduce animation complexity on mobile.

Limit simultaneous animations.

Lazy-load heavy media.

Prioritize above-the-fold content.

---

# Touch Targets

# Responsive Behavior

Hide decorative elements on mobile if necessary.

Never hide essential content.

Stack layouts before shrinking text.

Avoid horizontal scrolling.

# Responsive Do's

✔ Design Mobile First

✔ Test on real devices

# Responsive Don'ts

✘ Shrink text excessively

✘ Create separate mobile websites

✘ Hide important actions

✘ Break component consistency

✘ Ignore landscape orientation
