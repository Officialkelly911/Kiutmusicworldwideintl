PHASE 11F — SEARCH, PERFORMANCE & MEASUREMENT

Objective

Complete the remaining technical SEO, production performance, and analytics validation work identified during the Phase 11A SEO audit.

This phase must measure first, optimize second, and verify third.

Preserve all approved KIUT Music design, content, functionality, routing, branding, and previously completed SEO work.

Completed phases that must remain intact

* Phase 11B — Initial HTML SEO metadata
* Phase 11C — Server-level 404 handling
* Phase 11D — Structured data / entity SEO
* Phase 11E — Accessibility, mobile UX, and runtime reliability

Do not regress any of these implementations.

4. HERO VIDEO & LARGE MEDIA OPTIMIZATION

Audit all large video assets, especially:

* homepage hero video
* Creative Portfolio video
* Music page hero video
* Videos page media
* Tour page media
* other autoplay/background videos

For each video determine:

* file size
* dimensions
* codec
* duration
* preload behavior
* autoplay behavior
* whether it is above the fold
* whether it has a poster
* whether mobile users actually need to download it immediately

Optimize only where evidence supports it.

Required principles

Do not remove approved creative media.

Do not noticeably degrade visual quality.

Use appropriate:

* poster images
* preload
* lazy loading
* responsive loading strategies
* mobile-specific behavior where justified
* deferred loading for below-the-fold media

For decorative/background videos, ensure the browser does not unnecessarily download large assets before they are needed.

For meaningful video content, preserve accessibility improvements from Phase 11E.

6. YOUTUBE & THIRD-PARTY MEDIA

Audit all embedded third-party media.

Review:

* iframe loading
* lazy loading
* thumbnail strategy
* autoplay
* unnecessary third-party requests
* preconnect
* privacy-enhanced YouTube options where compatible
* iframe accessibility/title attributes

Avoid loading expensive third-party resources before the user needs them.

Do not change the approved media experience unnecessarily.

7. JAVASCRIPT & ROUTE PERFORMANCE

* bundle sizes

Preserve the existing route architecture.

Do not replace the application’s framework or routing architecture.

Do not introduce a new framework simply to improve one performance metric.
