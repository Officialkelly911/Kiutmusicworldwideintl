MUSIC PAGE HERO VIDEO — ZOOM & PLAYBACK FIX

The video currently being used as the Music page Hero background/hero visual is too heavily zoomed in, causing important portions of the video content to be cropped.

Additionally, the video is currently not playing correctly.

Please fix both issues without redesigning the Music page Hero.

1. Reduce the Video Zoom

Adjust the existing Music page Hero video so that the framing is slightly more zoomed out and more of the original video composition is visible.

The objective is to:

* Reveal more of the original video content.
* Keep the main subject/focal point clearly visible.
* Prevent unnecessary cropping.
* Preserve the video’s original aspect ratio.
* Avoid stretching or distortion.
* Maintain the cinematic Hero presentation.

Inspect the current implementation first and determine whether the excessive zoom is being caused by:

* object-fit: cover
* Container dimensions
* Fixed Hero height
* object-position
* CSS transforms
* Scale animations
* Responsive breakpoint rules
* Another component-level styling rule

Fix the actual cause rather than applying an arbitrary workaround.

2. Do Not Over-Zoom on Different Devices

Ensure the improved framing works across:

* Large desktop
* Desktop
* Tablet
* Mobile portrait
* Mobile landscape

The video should not look appropriately framed on desktop but become excessively zoomed on mobile.

Use responsive positioning and sizing where necessary.

If object-position needs to be adjusted, use an intentional focal-point position rather than arbitrary pixel offsets.

3. Restore Reliable Video Playback

Ensure the Music page Hero video actually plays when the page loads.

The intended behavior should be:

* Autoplay
* Muted
* Loop
* Plays inline
* No browser controls unless explicitly required by the existing design
* No unexpected audio
* Works on supported desktop and mobile browsers

Use the correct HTML/video attributes, including where appropriate:

autoplay
muted
loop
playsinline

If the project uses React/Next.js, ensure the video implementation correctly handles browser autoplay restrictions.

Do not rely on JavaScript alone to force autoplay if the browser requires the video to be muted.

4. Check the Video Source

Verify that:

* The correct video file is being referenced.
* The file path is valid.
* The video format is browser-compatible.
* The video actually loads successfully.
* There are no 404 or failed network requests.
* The browser can decode the video.
* The video is not being prevented from playing by another component or overlay.

If a poster image is being displayed indefinitely because the video fails to load or play, identify and fix the underlying issue.
