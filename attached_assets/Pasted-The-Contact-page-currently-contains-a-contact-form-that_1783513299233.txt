The Contact page currently contains a contact form that requires a production-ready backend. Your task is to implement a secure, reliable contact form that sends messages to the official Kiut Music contact email while preserving the website's existing design and user experience.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
OBJECTIVE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Connect the Contact Form to a real backend so that every submitted message is:

• Validated
• Securely processed
• Delivered to the official contact email
• Optionally stored in the database
• Logged for debugging
• User-friendly

Do not modify the visual design of the Contact page.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
EMAIL DESTINATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Create a configurable environment variable for the recipient email.

Example:

CONTACT_EMAIL=contact@kiutmusic.com

Do not hardcode email addresses inside the source code.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
BACKEND IMPLEMENTATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Implement a secure backend endpoint.

Recommended stack:

• Resend API (preferred)
or
• SendGrid
or
• EmailJS (only if server-side options are unavailable)

The backend should:

• Receive form submissions
• Validate all fields
• Sanitize inputs
• Send the email
• Return proper success and error responses
