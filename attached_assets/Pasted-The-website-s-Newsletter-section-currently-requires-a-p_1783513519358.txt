The website's Newsletter section currently requires a production-ready backend. Your task is to connect the newsletter signup form to both a secure database and a professional email marketing platform while preserving the existing premium user experience and visual design.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
OBJECTIVE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Implement a complete newsletter subscription system that:

• Validates email addresses
• Prevents duplicate subscriptions
• Stores subscribers securely
• Syncs subscribers with the mailing platform
• Optionally sends a welcome email
• Provides a polished user experience

Do not redesign the Newsletter section.

Use Mailchimp as the primary mailing platform.

If Mailchimp integration is not available, implement the architecture so another provider (Brevo, ConvertKit, etc.) can easily be substituted.

DATABASE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Store every subscriber in the database.

Suggested fields:

• id
• email
• subscribedAt
• status
• source (Website Newsletter)
• createdAt
• updatedAt

Prevent duplicate email addresses.

EMAIL VALIDATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Required field
• Duplicate subscriptions

Reject invalid submissions with clear, user-friendly messages.

SUBSCRIPTION FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Upon successful submission:

1. Validate email.
2. Check for duplicates.
3. Save subscriber to the database.
4. Add subscriber to the Mailchimp audience.
5. Return a success response.
6. Display a confirmation message.
7. Optionally send a welcome email.
