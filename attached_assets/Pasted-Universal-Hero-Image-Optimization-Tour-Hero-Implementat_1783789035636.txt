Universal Hero Image Optimization & Tour Hero Implementation

Objective

Implement the new Tour page hero image while creating a single universal responsive image system that automatically serves optimized hero images across the entire Kiut Music website.

This is not a Tour page-only implementation.

It must become the image architecture used by every page throughout the website.

⸻

Hero Image System

Create a reusable <HeroSection /> component that supports:

* responsive image loading
* optimized image variants
* focal point positioning
* lazy loading
* preload for above-the-fold heroes
* automatic format selection
* future image replacement without changing layout

The component should accept:

* image
* mobileImage
* alt
* overlay strength
* hero height
* focal point
* CTA content
* title
* subtitle

Every page should reuse this exact component.

⸻

Mobile Composition

Instead of shrinking the desktop image:

Recompose.

Center the artist naturally.

Preserve facial visibility.

Preserve skyline.

Avoid cutting off the body.

Maintain breathing room around the subject.

⸻

Overlay

Instead of darkening the entire image:

Use a subtle premium gradient.

Left side:

Dark transparent overlay.

Right side:

Minimal overlay.

This improves text readability while preserving the photography.

Loading Performance

Hero images should:

Lazy load below-the-fold images.

Preload only the current page hero.

Decode asynchronously.

Use fetchpriority=“high”

Prevent layout shift.

Reserve image dimensions before loading.

Target Lighthouse scores above 95.

⸻

Accessibility

Every hero image requires meaningful alt text.

Decorative overlays should be ignored by screen readers.

Maintain WCAG contrast for overlaid text.

⸻

Reusable Architecture

This responsive hero system should become the standard for every page.

Future hero images should only require replacing the source image.

Everything else should automatically generate and function without additional coding.

⸻

Expected Result

The Kiut Music website should have a world-class, responsive hero image system that:

• delivers razor-sharp imagery on every device

• avoids awkward cropping

• improves loading speed

• enhances SEO and Core Web Vitals

• preserves luxury visual quality

• provides a reusable foundation for every current and future page

The new Tour page hero should feel cinematic, premium, immersive, and seamlessly integrated with the existing Kiut Music design system while leaving all existing premium interface components untouched.
