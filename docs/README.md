# Kiut Studio Handbook

## Overview

The Kiut Studio Handbook is the official documentation system for the Kiut Music website project.

It defines the brand identity, design system, component standards, animation principles, development workflow, and long-term product vision for the platform.

This handbook exists to ensure that every future update remains visually consistent, technically maintainable, and aligned with the artistic direction of the Kiut brand.

---

## Project Status

**Current Phase:** Foundation & Design System

**Target Release:** Kiut Music Website v1.0

**Platform:** Replit + React + TypeScript + Tailwind CSS

**Primary Device Workflow:** Mobile-first development with Replit Agent assistance

## Core Principles

- Music First
- Cinematic Storytelling

- Consistency Over Novelty
- Mobile-First Experience
- Purposeful Motion
- Accessible Interactions
- Performance-Conscious Design

## How to Use This Handbook

1. Read `START_HERE.md` first.
2. Review the Project Vision before proposing new features.
3. Follow the Design System for all UI changes.
4. Update documentation whenever major components are added or changed.
5. Treat this handbook as the single source of truth for the project.
