---

## Development Workflow

Every feature should follow this sequence:

Idea → Blueprint → Design Review → Replit Prompt → Implementation → Testing → Polish → Documentation Update

Do not skip documentation.

---

## Important Rules

- Do not invent new colors outside the Design System.
- Do not introduce new spacing values arbitrarily.
- Do not create additional button styles without updating the handbook.
- Preserve mobile responsiveness at all times.
- Keep animations subtle and intentional.
- Maintain the premium black-and-gold aesthetic.

---

## Replit Agent Usage

When using Replit Agent:

- Reference the Kiut Design System.
- Implement one page at a time.
- Avoid unrelated refactors during focused upgrades.
- Preserve existing functionality unless explicitly instructed otherwise.

---

## Goal

The objective is not simply to build a website.

The objective is to create a memorable digital music experience that feels cinematic, premium, and uniquely connected to the Kiut brand.
