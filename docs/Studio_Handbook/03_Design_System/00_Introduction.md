# Introduction

Welcome to the Kiut Studio Design Language (KSDL).

This document serves as the foundation of every visual and interactive decision across the Kiut Music website.

The purpose of this Design System is to create a consistent, premium, cinematic, and memorable experience that reflects Kiut's artistic identity while ensuring long-term scalability and maintainability.

Rather than treating each page as an independent design, KSDL establishes a shared visual language that unifies every screen, animation, component, interaction, and layout.

Every future feature, page, section, and enhancement should reference this document before implementation.

---

# Mission

Create one of the most premium artist websites on the internet through thoughtful design, cinematic storytelling, elegant motion, and a unified user experience.

The website should feel less like a traditional website and more like a digital experience.

# Design Philosophy

The Kiut website follows five core principles.

## 1. Music Comes First

The interface should support the music rather than compete with it.

Visual effects should enhance the experience without distracting from the content.

---

## 2. Luxury Through Simplicity

Luxury is created through restraint.

Use generous spacing, elegant typography, refined color palettes, and subtle motion.

Avoid unnecessary visual clutter.

---

## 3. Cinematic Storytelling

Each page should feel like part of a larger narrative.

Scrolling should reveal content naturally, with carefully timed animations and transitions.

---

## 4. Consistency Creates Trust

Every page should feel like it belongs to the same product.

Buttons, cards, spacing, typography, animations, and interactions should remain consistent throughout the website.

---

## 5. Every Detail Matters

Premium experiences are built from small details.

Hover animations, loading states, transitions, spacing, lighting, and typography all contribute to the overall perception of quality.

# Global Design Rules

The following rules apply to every page.

- Never introduce new colors outside the Design System.

- Never invent new spacing values.

- Never invent additional typography styles.

- Always use reusable components.

- Keep animations purposeful.

- Prioritize readability.

- Design mobile-first.

- Preserve accessibility.

- Maintain visual consistency.
