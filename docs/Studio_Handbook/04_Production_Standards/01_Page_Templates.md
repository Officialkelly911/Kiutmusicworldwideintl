# Kiut Studio Design Language (KSDL)

# 13 – Page Templates

Version: 1.0

Status: Active

Last Updated: July 2026

---

# Purpose

This document defines the official page structures for every page on the Kiut Music website.

Every future page must follow one of these approved templates.

Layouts should remain consistent while allowing creative flexibility.

---

# Global Page Structure

Announcement Bar (Optional)

↓

Navigation

↓

Hero Section

↓

Primary Content

↓

Supporting Content

↓

Call To Action

↓

Footer

Every page follows this hierarchy.
