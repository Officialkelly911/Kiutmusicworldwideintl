# Kiut Studio Design Language (KSDL)

# 14 – UI Patterns

Version: 1.0

Status: Active

Last Updated: July 2026

---

# Purpose

The UI Pattern Library defines how reusable interface components should be combined throughout the Kiut Music website.

Patterns improve consistency, usability, and development speed while preserving the premium visual identity.

Patterns are reusable experiences, not reusable components.

---

# Design Philosophy

Every interaction should feel familiar.

Every layout should reinforce the Kiut brand.

Users should instinctively understand how to navigate every page.

# Featured Content Pattern

Featured item occupies 60% width.

Supporting items occupy remaining space.

Featured content should always receive visual emphasis.

# Gallery Pattern
