# Kiut Studio Design Language (KSDL)

# 16 – Asset Guidelines

Version: 1.0

Status: Active

Last Updated: July 2026

---

# Purpose

The Asset Guidelines define how every visual and media asset should be created, optimized, stored, and used throughout the Kiut Music website.

These standards ensure visual consistency, fast loading, maintainability, and a premium user experience.

---

# Design Philosophy

Every asset should be:

- High Quality

- Optimized

- Consistent

- Accessible

- Brand Approved

Every uploaded file represents the Kiut brand.

# Naming Convention

Use lowercase.

Separate words with hyphens.

Examples

hero-home.webp

featured-album.webp

tour-berlin-2027.webp

vip-fan-card.webp

Never use spaces.

Never use random filenames.

---

# Versioning

Replace outdated assets.

Archive previous versions.

Never overwrite important originals.

Maintain backups.

---

# Accessibility

Meaningful alt text.

Captions for videos where appropriate.

Readable text in graphics.

Avoid embedding essential information inside images.

---

# Performance

Compress images.

Lazy-load media.

Serve responsive image sizes.

Use CDN where available.

Preload only critical assets.

---

# Copyright

Only use:

Owned assets

Licensed assets

Official partner assets

Properly attributed media where required.
