## Standing Instructions for All Phases

Read the Studio Handbook and the Implementation Roadmap before making any code changes.

Follow the roadmap phase-by-phase.

Do not skip phases.

Do not combine multiple phases into one implementation unless they are tightly coupled.

---

## At the Beginning of Each Phase

1. Analyze the existing implementation.
2. Determine affected files.
3. Identify reusable components.
4. Review dependencies.
5. Plan implementation.

---

## During Each Phase

- Preserve existing functionality.
- Improve maintainability.
- Maintain responsiveness.
- Maintain accessibility.
- Maintain performance.
- Use design tokens.
- Reuse existing components.
- Follow the Kiut Studio Design Language.

---

## At the End of Each Phase

- Verify visual consistency.
- Verify responsive behavior.
- Verify accessibility.
- Verify performance.
- Verify component reusability.
- Update documentation where necessary.

---

## Phase Completion Report

Produce a completion report at the end of every phase containing:

- Phase completed
- Files modified
- Components reused
- Components created
- Performance improvements
- Accessibility improvements
- Documentation updated
- Remaining recommendations

---

## Gate Rule

Do not proceed to the next phase until the current phase is complete and verified.

# Purpose

This roadmap defines the official implementation sequence for upgrading the Kiut Music website.

Every phase should be completed and verified before moving to the next phase.

Never skip phases.

Never implement features outside the current phase unless required as a dependency.

---

# MASTER OBJECTIVE

Transform the existing website into a world-class premium artist platform while maintaining:

• Visual consistency
• Accessibility
• Performance
• Responsiveness
• Scalability
• Maintainability
